# Библиотека Миши — интерактивный прототип

Дважды нажмите **START_LIBRARY.cmd**. Откроется http://127.0.0.1:8768.
Для повторного открытия используйте тот же файл. После перезагрузки компьютера запустите его снова.

В каталоге можно:
- искать по названию, автору, ISBN и заметкам;
- переключать карточки и таблицу, фильтровать категорию и чтение;
- открывать, добавлять, редактировать и удалять записи;
- отмечать любимые книги и статус чтения;
- добавлять свои обложки JPG/PNG/WebP (до 10 МБ, в прототипе уменьшаются до 900 пикселей);
- работать со списком «Нужно уточнить»;
- скачивать и восстанавливать полную JSON-копию с обложками.

## Где сохраняются данные

`data/library.json` — рабочие данные. `data/library.previous.json` — предыдущая сохранённая версия.
`seed.json` — начальный снимок: 287 записей каталога и 55 записей очереди проверки.
Исходные catalog_misha_books.xlsx/json/csv не изменяются.
342 записи не означают 342 уникальные физические книги: список ещё требует сверки.
Копии скачивайте регулярно кнопкой «Скачать копию». «Загрузить копию» принимает именно такой файл и заменяет рабочую версию после подтверждения.

## Границы прототипа

Приложение работает только на этом компьютере. Сейчас это Python-сервер без внешних зависимостей и файловое хранилище, не итоговый FastAPI/PostgreSQL backend. Telegram, учётные записи, автоматический поиск обложек и метаданных, импорт XLSX ещё не подключены.
Обложки в прототипе хранятся в рабочем JSON; оригинал загруженного изображения остаётся у владельца. Для окончательного приложения предусмотрено отдельное хранилище оригиналов и миниатюр.
При одновременной правке из двух вкладок устаревшее сохранение отклоняется: скопируйте введённый текст и обновите вкладку.
Сервер слушает только 127.0.0.1. Не используйте этот сервер для публикации в интернете.

Для разработки: `python server.py`. Переменные `MISHA_LIBRARY_PORT` и `MISHA_LIBRARY_DATA` задают порт и папку данных; штатный запуск использует 8768 и `prototype/data`.
